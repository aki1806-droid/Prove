# Prompt immagini e clip – R01 Reel manifesto «Credevo di crescerli»

## Come usarli

1. Apri una chat nuova di ChatGPT e incolla per primo il blocco STILE qui sotto, scrivendo: «Usa questo stile per tutte le immagini che ti chiederò».
2. Poi incolla un prompt alla volta. Formato: **verticale 2:3 (1024×1536), poi ritaglio a 1080×1920**.
3. Salva ogni immagine nella cartella `immagini/` con il nome indicato.
4. Per le scene «clip»: carica l’immagine su Higgsfield (image-to-video, 5 s, 1080p) con il prompt di movimento; salva il .mp4 in `clip/` con lo stesso nome.

## STILE (incollare una volta)

```
Stile «Notturno luminoso»: fotografia cinematografica notturna, luce lunare blu-argento, una sola fonte di luce calda che sembra nascere dall'oggetto principale; palette blu notte #0B1A2E, blu marea #1C3A5E, argento #DCE4EC, bagliore avorio #FFF8E7, tocchi di verde salvia #7FA79A; piccole particelle luminose sospese come polvere di stelle; grana fine da pellicola 35 mm, profondità di campo ridotta, silenzio, poesia, realismo fotografico. Nessun testo, nessuna scritta, nessun logo. Bambini solo di spalle, in controluce o nelle mani: mai un volto riconoscibile.
```
